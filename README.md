# Simple 2D Java Game Engine

## A small, self-contained 2D game engine written in Java. The project implements core systems
## commonly used in tile-based games: rendering, player camera, collision detection, keyboard/mouse
## input, simple map format, and resource management — implemented with no external libraries so
## it is easy to read and extend.

# Features
## - Tile-based map rendering (map array + tileset)
## - Player entity with movement and collision detection
## - Camera following player
## - Basic NPC entity support
## - Keyboard and mouse input handling
## - Simple audio helpers for music and SFX ( NOT DONE )
## - Resources folder with sprites, tilesets and UI assets

# Requirements
## - Java 17+
